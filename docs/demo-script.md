# Demo script (about 3 minutes)

Preparation: run in the mode you will claim (say "Demo mode" out loud if it is). Open Admin once to warm the workspace.
Check the hackathon rules for required video length and hosting.

| Time | Do | Say |
|---|---|---|
| 0:00 | Landing page | "Tickets get marked resolved without being fixed. CivicClosure checks the evidence before it closes one." |
| 0:15 | Click an evidence option in the walkthrough | "This walkthrough is scripted. Now the real thing." |
| 0:30 | Report: **Broken stair light** sample, Submit | Point out the complaint ID, department, deadline and the decision trail with the model or rules label. |
| 1:00 | Submit the same sample text again from the form | "A second report of the same problem merges into one ticket with a report count." |
| 1:15 | Role: Department, open the ticket, sample evidence **Reused original photo**, Claim | Verdict **Contradicted**: reused photo, capture time and unchanged light. |
| 1:45 | Sample evidence **Genuine repair photo**, Claim | **Verified**, and the ticket closes. "Only the gate or a human can close it." |
| 2:00 | Admin: +24 hours on the demo clock | "Labelled demo clock. Escalations it causes are flagged simulated." |
| 2:15 | Ticket page: **Verify audit integrity** | "Every event is hash-chained. Tamper-evident, not tamper-proof." |
| 2:30 | Admin: hotspots, then Evaluation | "Four leak reports at one hostel become one work order." Read the note under Evaluation: synthetic data, demo or live mode. |
| 2:50 | Close | State the limits: evidence checks are not proof; role switcher is not authentication. |

Never present Demo Mode output as NVIDIA model output. If you have run live mode, show the model names in the decision trail and the Nebius job logs.
